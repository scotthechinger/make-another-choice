# Make Another Choice (Shelby County)

Working prototype by Zealous with Just City.

- `public/index.html` is the whole site. Fonts are embedded, so it works offline.
- `server.js` serves it with a shared password when `PREVIEW_USER` and `PREVIEW_PASS` are set.

To update the site, replace `public/index.html` and push. Render redeploys on its own.
